## Featured Projects

### 🎮 [One Minute Left](https://github.com/scn01/one-minute-left) &nbsp;·&nbsp; Browser Platformer
> *Vanilla JS · HTML5 Canvas · Adaptive Difficulty · Ghost Replay*

A browser platformer built entirely without an engine. The player must finish levels with **exactly one minute remaining** time pressure as a core mechanic, not a countdown.

- **Ghost replay system**: records and replays full player-state data frame-by-frame, a technique used in titles like *Celeste* and *Trials*
- **Adaptive difficulty engine**: samples real-time performance and adjusts obstacle speed/spawn rate across 3 tiers, no manual tuning required
- **Hidden speedrun path** : shortcut reduces optimal route by ~40%, discovered organically through play

### 🃏 [MNMX Memory Battle](https://github.com/scn01/mnmx-memory-battle) &nbsp;·&nbsp; AI Card Game
> *JavaScript · CSS3 · Probabilistic AI · Web Audio API*

A memory card game with an AI opponent that actually remembers — not a random bot.

- **Bayesian-style memory AI**: weights move decisions against a running history of revealed cards, not random selection
- **5 progressive difficulty tiers**: tune AI aggression and memory retention independently, extending average session length
- **Refactored mid-development** from a single-file prototype to a clean MVC multi-file architecture
